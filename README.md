# 🧬 Genetik & DNA Mutasyon Simülatörü

Bu proje, girdiği DNA dizilimleri üzerinde belirtilen oranlarda rastgele nokta mutasyonları gerçekleştirir. Elde edilen mutasyonlu dizilimi ve biyolojik etkilerini Hugging Face Inference API (Mistral-7B) entegrasyonu ile analiz eder.

## 🌟 Özellikler
- **Dinamik Mutasyon:** A, T, G, C bazları üzerinde özelleştirilebilir oranlarda nokta mutasyonu.
- **AI Biyoloji Analizi:** Transkripsiyon, protein sentezi ve hücresel/fenotipik etkilerin analizi.
- **AP Biyoloji Düzeyi:** Otomatik soru ve çözüm üretimi.
- **İnteraktif Arayüz:** Streamlit tabanlı web arayüzü.

## 🛠️ Kullanılan Teknolojiler
- Python 3.11+
- Streamlit
- Hugging Face Inference API / LLM (Mistral-7B-Instruct)
